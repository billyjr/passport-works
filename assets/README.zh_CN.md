# 素材与隐私

`images/tuner/` 为生成的界面参考，不是实测截图。
`images/personal-card/` 为通过代码绘制的通用创客模板及 LVGL RGB565 C 资源，
文字已嵌入图像。

`private/billy/` 仅限本地并被 Git 忽略，保留原始头像、名片源图、转换素材和生成提示词。
这些可识别个人素材的再分发许可尚未确定，不得提交或进入公开固件产物。
本地名片构建在素材存在时使用它们。

头像、凭证、二维码秘密、EXIF 位置和原始日志不进入 Git。
模板不含个人头像或联系方式。应用设计参考和通用模板可随 MIT 源码再分发，
但不包括私人头像和第三方素材。
